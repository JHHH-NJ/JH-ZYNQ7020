# JH-ZYNQ7020 FPGA Demo

- `01_LED`：LED 闪烁
- `02_KEY_LED`：按键控制 LED
- `03_Breath_LED`：呼吸灯
- `04_PLL`：PLL 时钟实验
- `05_Single_Port_RAM`：单端口 RAM，2048 × 16，单口读写
- `06_Dual_Port_RAM`：简单双端口 RAM，16 位写入、8 位读取，50/75 MHz
- `07_Asynchronous_FIFO`：异步 FIFO 与位宽转换
- `08_UART_LOOPBACK`：UART 串口环回（115200、8N1）
- `09_RS485`：RS-485 半双工数据回传
- `10_HDMI_ColorBar`：HDMI 720p 五色彩条显示

目标板：JH-ZYNQ7020-F V1.0，器件 `XC7Z020-2CLG484I`（Vivado `PART`：`xc7z020clg484-2`），Vivado 2023.1。
