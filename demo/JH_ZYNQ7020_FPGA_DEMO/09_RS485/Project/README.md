# 09_RS485 串口通信实验

目标板：JH-ZYNQ7020-F V1.0；器件：`xc7z020clg484-2`；Vivado 版本：2023.1。

## 文件与工程设置

- `Source/jh_rs485_top.v`：JH 板级顶层，PL_KEY1 低有效复位，异步拉低、两级同步释放。
- `Source/uart_rx.v`、`uart_tx.v`、`uart_test.v`：UART 收发及 RS-485 帧处理逻辑。
- `Project/IP/rx_fifo/rx_fifo.xci`：FIFO Generator 配置，公共时钟、8 bit 宽、256 字节深。
- `Constraint/JH_RS485.xdc`：50 MHz 时钟和 JH 板卡第一路 RS-485 管脚约束。

在 Vivado 2023.1 中新建器件为 `xc7z020clg484-2` 的工程，添加 `Source` 和 `Constraint`，并将 `Project/IP/rx_fifo/rx_fifo.xci` 导入工程后生成 IP 输出文件；设计顶层设为 `jh_rs485_top`。建议将 XCI 导入或复制到新工程再生成 IP，避免直接引用旧 XCI 时沿用原工程的生成目录。

## 板级连接与帧格式

| 信号 | FPGA 管脚 | 说明 |
| --- | --- | --- |
| `i_clk` | W17 | PL 50 MHz 时钟 |
| `rst_n` | W18 | PL_KEY1，低有效 |
| `rs485_rx1` | AA19 | 第一通道接收 |
| `rs485_tx1` | W22 | 第一通道发送 |
| `rs485_de1` | Y20 | 第一通道方向控制，高电平发送 |

以上端口均在 Bank33，使用 `LVCMOS33`。USB 转 RS-485 的 A/B 接开发板第一路 `1A/1B`，具体正负标识以转换器说明书为准。串口为 115200 baud、8N1。发送帧为 `55 + 长度 + 数据`，长度范围为 1～255；板端只回传数据，不回传帧头和长度。例如发送 `55 08 01 02 03 04 05 06 07 08`，应收到 `01 02 03 04 05 06 07 08`。下载后可按住 PL_KEY1 约 1 秒再松开以复位。

## 已有验证与限制

本例所用核心 RTL、FIFO 配置、JH 顶层和板级 XDC 与此前 Vivado 2023.1 验证所用文件一致。2026-11-13 的 XSim 仿真检查了零长度、1 字节及 8 字节帧；综合实现生成位流。2026-11-14 的第一路板级测试覆盖零长度、单字节及两组八字节帧，回传符合预期；首次上电下载后无回传，按键复位后恢复，具体原因未确定。

此前实现报告有 FIFO RAMB 控制信号异步复位相关的 REQP-1840 警告；输入/输出端口未设置外部 I/O 延迟约束，内部时序结果不代表完整接口时序签核。未覆盖 255 字节、误码和连续复位场景。本例程根目录已保留 Vivado 工程和生成产物；源码与工程说明分别位于 `Source` 和 `Project/README.md`。
